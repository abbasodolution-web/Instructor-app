# Error Practice App

Install this module on your Odoo 15 Enterprise local system.

Your task is to fix the errors one by one.

For each error, submit:

1. Error screenshot
2. Root cause
3. File changed
4. Fix applied
5. Final working screenshot

Do not rewrite the whole app. Fix only the issue shown by Odoo.

Expected output:

- The module installs successfully.
- The menu `Error Practice > Practice Tickets` opens.
- A practice ticket can be created.
- Remaining hours computes correctly.
- The `Start` and `Done` buttons work.
